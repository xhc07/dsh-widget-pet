# 已知问题：详细用量同名对话重复显示

> 状态：已记录，未改代码。

## 1. 现象

「详细用量 → 按对话」中，同一个对话标题可能出现多行。

例如：

```text
把 Claude 娘做成 DSH 余额挂件   ¥1.20
把 Claude 娘做成 DSH 余额挂件   ¥0.35
```

## 2. 根因

当前聚合按 `sessionId` 分组：

```js
const key = sessionId || 'legacy'
```

同一标题可能对应多个不同 `sessionId`：

- 用户新建了多个同名对话；
- 标题被重命名后复用；
- 旧数据没有 sessionId，落在 `legacy`；
- 子代理默认为 `子代理`，多个不同子代理 sessionId 都会显示成同名多行；
- 子代理和主会话也可能同名。

因此“名字相同”不等于“同一个会话”，当前会按不同 key 显示多行。

特别是子代理：

- 每个子代理是不同 sessionId；
- 父任务可能有多个子代理；
- 现在都显示为“子代理”，所以会重复多次。

修复时要区分：

- 主对话同名；
- 子代理同名；
- 是否要按父会话归并。

## 3. 修复选项

### 方案 A：按标题合并（推荐如果用户只想看名字）

同一天内按规范化后的 `sessionName` 合并：

- 成本相加；
- 保留 `sessionIds` 数组；
- 显示“2 个会话”或悬浮提示 ID 列表；
- 标题相同就一行；
- 子代理的“子代理”合并成一行，并显示子代理数量。

优点：不再重复。
缺点：不同会话/不同子代理被合并，不能单独看每个会话。

### 方案 B：保留多行，但加唯一后缀

```text
同名对话 · 1
同名对话 · 2
```

或显示短 sessionId。

优点：保留区分。
缺点：仍然多行，只是不再看起来完全重复。

### 方案 C：按标题合并，展开后显示子会话

```text
同名对话   2 个会话   ¥1.55
  会话 1   ¥1.20
  会话 2   ¥0.35
```

兼顾总览和明细，但 UI 更复杂。

## 4. 建议

优先方案 A；合并后允许点击展开子会话。

合并键建议：

```text
day + sessionName（trim）
```

同名但不同 sessionId 的会话：

- 成本相加；
- `sessionIds` 保留；
- 显示“2 个会话 / 3 个子代理”；
- 点击展开后显示每个子项；
- 子项显示短 ID，超长省略；
- 鼠标悬浮约 1 秒后显示完整 ID 悬浮框；
- 移开鼠标立即消失；
- 悬浮框限制最大宽度、自动换行，不能撑爆面板。

子代理单独分组：

- 主对话同名合并；
- 子代理按“子代理”合并，显示数量；
- 展开显示每个子代理 ID；
- 旧数据没有 sessionId 时显示“旧记录”。

## 5. 测试场景

- 同一标题、不同 sessionId；
- 同一 sessionId、标题发生变化；
- 旧数据 sessionId 为空；
- 大小写/空格差异；
- 子代理同名；
- 同一天多个同名对话；
- 跨天同名对话（按天分开，不跨天合并）。
