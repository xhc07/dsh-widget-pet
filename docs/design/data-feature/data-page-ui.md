# 数据页 UI 规划（按大类分组）

> 状态：设计，未改插件代码。
> 原则：相邻设置项功能相似；复杂操作进独立窗口/弹窗；不把实验功能塞进数据页。

## 1. 页面结构

设置第五个大类：

```text
角色 / 显示 / 声音 / 提醒 / 数据 / 实验
```

数据页从上到下：

1. 数据概览
2. 展示口径
3. 导入
4. 导出
5. 备份与还原
6. 清理数据
7. 第三方价格入口

## 2. 数据概览

只读卡片/行：

```text
本地账本
  事件数         244
  逐日汇总       25 天
  账本大小       45 KB
  最早/最新      2026-11-01 ~ 2026-11-25

官方导入
  文件数 / 日期范围 / 时区

备份
  自动备份状态   关闭
  上次还原点     2026-11-28 00:00
```

不放编辑控件，只做状态展示。

## 3. 展示口径

相邻项放一起：

```text
默认展示口径     [仅 DSH / 官方账号 / 总费用]
高级覆盖         [折叠]
  余额           [跟随默认 / 仅 DSH / 官方账号 / 总费用]
  今日已用       ...
  徽章           ...
  图表           ...

主货币           [CNY / USD / ...]
```

- 默认「官方账号」；
- 高级覆盖默认折叠；
- 主货币只影响展示，不改底层原币金额。

## 4. 导入

```text
导入
  从插件 JSON 导入       [按钮]
  从官方 ZIP 导入         [按钮]
  最近导入记录           [列表]
```

点击后进入导入弹窗：

1. 选文件
2. 解析/校验
3. 时区提示
4. 冲突列表
5. 字段勾选
6. 导入模式：替换/覆盖/选择/取消
7. 强制备份
8. 高危确认

相邻项都是“导入”，放同组。

## 5. 导出

```text
导出
  插件 JSON 导出         [按钮]
  官方格式导出           [按钮/暂缓]
  字段/范围选择           [打开导出设置]
```

导出弹窗：

- 数据集分区；
- 字段勾选；
- 时间范围；
- 隐私字段；
- 版本信息。

## 6. 备份与还原

```text
备份与还原
  自动备份               [开关，默认关]
  触发                   [启动 / 每天 / 每周 / 每月 / 组合]
  备份范围               [全部 / 365 / 180 / 90 / 30 / 7 / 今天]
  备份内容               [数据类默认勾选，设置类默认不勾]
  自动清理               [开关，默认关]
    保留时间             [30 天]
    保留份数             [20 份]

  上次还原点             [恢复] [详情]
  备份列表               [列表/恢复/删除/保护]
  手动备份               [立即备份]
```

相邻项都是备份/恢复/清理，放同组。

## 7. 清理数据

```text
清理数据
  类别                   [ ] 本地事件
                         [ ] 逐日汇总/accounting
                         [ ] 归档
                         [ ] 官方导入
                         [ ] 备份
                         [全选]（不勾备份）

  时间模式               [近 / 前]
  时间跨度               [1/2/3/5/6/12/24 小时 / 1/2/3/5/7/14/30/60/180/365 天]
  包含今天               [ ] 默认不勾
  清理前备份             [✓] 默认勾选
```

- 类别默认全不选；
- 全选不勾备份；
- 包含今天勾选时红色警告；
- 高危确认。

## 8. 第三方价格入口

```text
第三方价格             [进入]
  管理 provider / 模型 / 价格段 / 多账户 / 汇率
```

点进去是独立大窗口，不在数据页内展开。

## 9. 不放在数据页的内容

- 实验功能 → 独立「实验」大类；
- 显示时区/时间格式 → 显示设置；
- 角色大小 → 显示设置或右键菜单；
- OOBE → 首次启动。

## 10. 默认值汇总

- 默认展示口径：官方账号；
- 主货币：CNY；
- 自动备份：关闭；
- 自动清理：关闭；
- 开启清理后默认：30 天 + 20 份；
- 备份范围：全部；
- 备份内容：不可还原数据；
- 手动备份：默认保护；
- 清理类别：全不选；
- 包含今天：不勾；
- 365 天：默认按周，可选按月。
