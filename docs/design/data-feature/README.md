## 已确认的核心结论

1. 主账本有自动保留策略，但归档和历史日汇总仍可能缓慢增长，目前没有清理入口。
2. 官方导出是“按天 × 模型 × 钱包/计费项”的账单，没有对话 ID；不能替代本地对话统计。
3. 官方与本地不是两套独立账本：官方是账号账单，本地 history 是同一账号的余额观测，本地 events 才是 DSH 逐轮记录。
4. 可实现“官方日优先、官方没有的日期回退本地”，按天只选一个来源，绝不把同一天相加。
5. 官方 CSV 含本地没有的字段，纯本地数据不能无损生成官方格式；官方格式导出仅适用于官方来源行，暂缓实现。
6. 图表跨度可行：总跨度 7/30/90/180/365，每柱 1天/1周/2周/1月/3月。
7. 先做本地功能：图表跨度、本地 JSON 导出、数据清理；官方导入和官方格式导出后续再做。
