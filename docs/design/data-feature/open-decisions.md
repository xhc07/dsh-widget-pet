# 数据功能 — 已定规则与剩余问题

> 2026-11-26 收敛版。未修改插件代码。

## 1. 核心规则（已定）

按天处理：

```text
官方有该天数据：
    本地没有 → 用官方
    本地也有且金额一致 → 用官方，不弹窗
    本地也有但金额不同 → 弹窗让用户选
官方没有该天数据：
    用本地
两边都没有：
    0
```

- 同一天绝不相加。
- “官方有数据”指该天实际存在官方 cost 行，不是只看 zip 声明范围。
- 官方数据独立存储，不混进本地 events/history。
- 弹窗选项：官方 / 本地 / 取高 / 取低。
- 弹窗可附“后面的冲突都按这个处理”，只作用于本次导入剩余冲突。
- 本地值默认取 `history` 余额观测；没有时取 events 估算；弹窗同时显示 events 估算作参考。

## 2. 展示口径（已定）

- 图表：按上面的逐日规则取一个来源，再做总跨度/每柱跨度聚合。
- 顶部「今日已用」：今天有官方数据用官方，否则用本地。
- 「余额」：始终来自实时余额接口，官方导入无法覆盖。
- 徽章：余额来自实时接口；今日数字按上面规则。
- 详细用量：官方日显示官方模型/钱包/计费项；本地日显示本地模型/对话。
- 官方日期没有对话 ID：按对话用本地明细，并标记“本地对话明细”。
- 官方格式导出：只导出官方存在的行/字段；不导本地独有内容。
- 官方格式空有格式，不代表 platform 支持反向导入。

## 3. 导入规则（已定）

- 完整解析、校验后再报告冲突。

## 5. 真正剩余的问题

- 清理对象：events / history / 归档 / 官方导入 / 备份？
- 清理前是否默认备份？
- 倒数确认秒数。

### 5.4 第三方中转价格

### 5.6 导出 JSON

### 5.7 性能

- 优化当前未使用的 `all.days` O(天数×事件数)。

## 6. 2026-11-26 第三轮回答

### 6.1 采样低于 60 秒为什么要绕缓存

- 前端每 60 秒请求，宿主缓存也 60 秒。
- 前端改成 30 秒但请求不带 `?refresh=1`，宿主仍返回 60 秒内的缓存，实际采样还是 60 秒。
- 要真正 30 秒采样，必须每次带 `refresh=1` 绕过缓存，或把宿主 TTL 降到 30 秒。
- 后果：余额接口调用次数翻倍、网络/电量增加、可能触发限流；采样更细也仍可能遇到余额延迟。

### 6.2 今日官方数据

- 增加“导入今日数据”按钮/勾选，默认不勾选。
- 今日官方行可能未结算完整，导入时提示“可能不完整”。
- 当前余额仍来自实时接口，不被官方导入覆盖。
- 今日是否锁定，需在实现时明确。

### 6.3 清理语义

已确认：

- “近 N 天” = 删除最近 N 天。
- “前 N 天” = 删除 N 天以前的数据。
- 小时同理。
- 仍需定：是否包含今天/边界日、清理哪些数据类别、是否备份、倒数秒数。

### 6.4 第三方价格重算

- 设置或修改第三方价格时弹窗，询问是否重算历史。
- 需要 provider/model 匹配、cache hit/miss/output 单价、峰谷、固定调用费、币种。
- 历史 events 目前只有总 tokens/cost，没有 cache 拆分和 provider；旧数据无法精确重算，只能从新记录开始，或做近似重算。

### 6.5 JSON 导出

- 默认“能导尽导”，按分区勾选。
- 包含：本地账本、归档、官方导入、设置、元信息；备份可选。
- 时间范围可选。
- 导入设置时带插件版本和 settings schema 版本：
  - 兼容：正常导入；
  - 不兼容：警告并允许“强制导入”；
  - 导入前备份。

### 6.6 性能/体积

当前包约 15.3 MB，主要由 assets 15.7 MB 构成；`claude-pet.js` 约 149 KB，lib 约 60 KB。

新增数据功能预计：

- 代码增量和 UI 很小，无新增图片/音频；
- 官方 30 天样本约 183 行，365 天约数千行，数据文件远小于现有 assets；
- 导入/导出/清理是一次性操作；
- 图表按日聚合 O(365)，替代当前无效的 O(天数×事件数)，可能更快；
- 365 天 + 每柱 1 天会有 365 个 DOM 柱子，需要提示或限制；
- 备份数量需要上限/清理。

结论：包体和常驻性能不会明显增加，主要风险是 365 根柱子和大量备份，而不是数据文件本身。

### 6.7 今日导入 UI

- 勾选框下方用注释字体写明：
  - “默认不勾选：今日官方数据可能未结算完整。”
- 勾选后注释变红。
- 当前余额仍来自实时接口。

### 6.8 清理包含今天

- 增加“包含今天”勾选框，默认不勾选。
- 勾选时，确认框增加一行红色提示：“今日数据会被删除。”
- 未勾选时，“近 N 天”从昨天往前算；“前 N 天”不受今天影响。

### 6.9 第三方价格自动发现

- DSH `assistant/message.source` 有 `provider` 和 `model`。
- 可自动记录 provider/model。
- 新 provider/model 可自动加入价格列表，标记“未配置”。
- 事件里通常没有 API key 名称、base URL、中转站显示名。
- 可手动添加 provider/model/价格。
- 历史 events 没有 provider，只能按模型名补。

详细设计见 `design/ui/third-party-pricing.md`。

### 6.10 备份

- 备份由数据页管理，支持列表、删除、数量上限。
- 不是无限自动堆积。

### 6.11 采样设置结构

- 右侧「默认」按钮，默认开启且高亮；
- 默认模式使用原有 60 秒请求/缓存规则；
- 关闭默认进入自定义模式，关闭时弹高危确认；
- 自定义滑块 1–300 秒，气泡和右侧秒数；
- 秒数可点击输入 1–999，需校验/夹取；
- 输入超过 300 时，滑块停在 300，右侧显示实际值；
- 1–59 秒必须绕过宿主缓存；1 秒会产生每分钟 60 次请求；
- 低于 60 秒有红色风险注释，高于 60 秒普通颜色注释；
- 不轮询，不按格弹；只在释放/提交时跨过 60 秒阈值弹一次；
- 取消恢复旧值。

### 6.12 高危倒数

- 提醒设置新增「高危项目操作倒数提醒」：关/3/5/10/15 秒，默认 10 秒。
- 管理除自己以外的所有高危弹窗。
- 设为「关」时，其他高危弹窗仍提示但不再倒数。
- 把自己设为「关」时，单独强制 15 秒，不受自身控制。
- 从「关」改回其他值不需要强制 15 秒。
- 清理、清空、导入覆盖、关闭采样默认等都算高危。

### 6.13 清理类别

- 类别默认全部不选；
- 增加“全选”按钮；
- “全选”不包含删除备份，备份需要单独勾选；
- 备份勾选默认开启；
- 清理包含今天默认不勾选；
- 高危倒计时默认 10 秒。

### 6.14 今日导入锁定

- 锁定不是硬写死，而是“官方今天优先”的覆盖层；
- 后续显式导入可以更新；
- 跨日/换机后锁定过期；
- 删除官方导入时解除；
- 导出 JSON 要带上覆盖/锁定元数据。

### 6.15 第三方多币种/多段

- 最多 30 段峰谷；
- 每段有生效时间/星期和价格；
- 事件保存原币金额、汇率、折算金额、配置版本；
- 汇率变化只影响新记录，历史冻结；
- 汇率表可手动维护；
- 第三方余额需要手动录入；
- 数据设置页增加“汇率获取”开关 + 下拉（自定义/汇率接口）；
- 网络汇率失败回退上次值并标记过期；
- 历史金额按当时汇率冻结。

### 6.16 JSON 无损迁移

- 默认全选、能导尽导；
- 包含本地账本、归档、官方导入、设置、价格配置、汇率、手动余额、覆盖/锁定元数据、版本信息；
- 换机导入目标：尽量恢复成原先一样；
- 导入模式提供：替换 / 覆盖 / 选择 / 取消；
  - 替换：清空当前后用导出数据恢复（换机用）；
  - 覆盖：按唯一键更新，保留未被导入的其他数据；
  - 选择：勾选分区/时间范围/冲突逐项导入；
  - 取消：不写入。
- 设置版本不兼容时警告，允许强制导入；
- 导入前备份。

### 6.17 历史重算

### 6.14 365 根 DOM 柱子

指图表每个柱子都是一个 HTML 元素。365 天 × 每柱 1 天 = 365 个 `.bar-col` 节点；虽然 365 个节点本身不算大，但面板宽度只有约 300px，每根不到 1px，且 hover/重绘更密。建议默认按周/月聚合，仍允许用户选 1 天但提示过密。
