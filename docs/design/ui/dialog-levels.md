# 统一弹窗与 0–5 危险等级（设计）

> 状态：规则草案，未改插件代码。
> 实现开始时必须把这套规范写入插件自己的设计文档（不是 README），建议路径：
> `dsh-widget-pet/docs/DESIGN_SPEC.md` 或 `docs/design/dialogs.md`。

## 1. 统一接口

所有弹窗共用一个服务：

```js
showDialog({
  level: 0 | 1 | 2 | 3 | 4 | 5,
  title,
  body,
  confirmText,
  cancelText,
  countdown,
  requireBackup,
  requirePhrase,
  onConfirm,
  onCancel,
})
```

统一：

- 同一时间只显示一个，后续排队；
- 左上角圆角色块标签；
- 色块无描边、像按钮，但不承担点击功能；
- 倒数、确认按钮禁用、取消、备份、失败回滚。

## 2. 等级与颜色

| Level | 标签 | 颜色 | 含义 | 倒数 |
|---:|---|---|---|---|
| 0 | 提示 | 主题色 | 普通信息 | 无 |
| 1 | 完成 | 绿色 | 成功/安全确认 | 无 |
| 2 | 注意 | 橙色 | 可恢复但有影响 | 无 |
| 3 | 危险 | 红色 | 可能丢数据/改口径 | 高危设置 |
| 4 | 严重 | 深紫/深红 | 不可逆/大范围 | 高危设置 |
| 5 | 系统 | 黑色 | 关闭高危设置自身 | 固定 15 秒 |

## 3. 1–4 的细分

### Level 1 绿色：完成/安全确认

- 操作成功；
- 无数据风险；
- 普通确认即可；
- 例：导出完成、备份完成。

### Level 2 橙色：注意

- 有影响，但可恢复；
- 不改数据或只改设置；
- 例：修改显示时区、切换主货币、恢复默认设置；
- 不强制倒数，但可以显示警告。

### Level 3 红色：危险

- 可能丢数据或改变统计口径；
- 需要高危倒数；
- 建议自动备份；
- 例：
  - 删除部分数据
  - 导入覆盖
  - 关闭采样默认模式
  - 覆盖本地观测

### Level 4 深紫/深红：严重

- 不可逆或大范围；
- 高危倒数；
- 弹窗内提供「操作前备份为 JSON」勾选框，默认勾选；
- 可取消备份，但必须有醒目的红色警告；
- 例：
  - 清空全部用量
  - 导入替换全部数据
  - 删除全部官方导入

备份规则：

- 备份格式与完整 JSON 导出一致；
- 包含当前要影响的数据 + 版本/时间元数据；
- 写入本地备份目录；
- 数据页可查看、恢复、删除；
- 备份失败时：
  - 勾选了备份：阻止操作并提示；
  - 取消备份：只显示风险确认。

默认勾选的意义是“默认安全”，不是强制。用户明确取消后仍可继续，但必须看到红色后果说明。

### Level 5 黑色：系统自身

- 只用于关闭「高危项目操作倒数提醒」；
- 独立固定弹窗；
- 固定 15 秒；
- 不受自身设置控制。

## 4. 确认弹窗设置（原“高危倒数”）

因为加入了 0–5 级，原「高危项目操作倒数提醒」应改名为：

```text
确认弹窗设置
```

可按等级配置：

| Level | 默认倒数 | 默认强制短语 | 默认备份 |
|---|---:|---|---|
| 0 提示 | 关 | 关 | 关 |
| 1 完成 | 关 | 关 | 关 |
| 2 注意 | 关 | 关 | 关 |
| 3 危险 | 10 秒 | 关 | 默认勾选 |
| 4 严重 | 10 秒 | 开，默认短语 `yes` | 默认勾选 |
| 5 系统 | 固定 15 秒 | 固定短语 `yes` | 不适用 |

每级可配置：

- 是否需要倒数；
- 倒数秒数（关/3/5/10/15，或自定义）；
- 是否强制输入确认短语；
- 短语内容，默认 `yes`，可选：
  - `yes`
  - `ok`
  - `iknow`
  - `确定`
  - `我已阅读并已知风险`
  - 自定义短语
- 是否默认勾选 JSON 备份。

控制规则：

- **所有等级**都可以单独开启/关闭倒数和短语，包括 Level 0；
- 默认只有高危级 Level 4 开启短语；
- Level 3 默认关闭短语；
- Level 5 永远固定 15 秒 + 固定 `yes`，不可调整；
- 把确认弹窗设置整体关闭时，自己的关闭弹窗仍固定 15 秒；
- 其他等级是否还倒数，取决于该级自己的设置。

## 5. 高危设置怎么控制

- 确认弹窗设置控制 Level 3 / Level 4；
- 关闭整体开关后，Level 3 / 4 仍警告，但按各自配置决定是否倒数；
- Level 0 / 1 / 2 默认不强制倒数；
- Level 5 永远固定 15 秒。

## 5. 色块标签

位置：弹窗左上角。

样式：

- 圆角矩形；
- 无描边；
- 背景为对应等级颜色；
- 白色文字；
- 小号；
- 视觉上像按钮，但不响应点击。

| 修改主货币 | 2 |
| 恢复默认设置 | 2 |
| 删除部分数据 | 3 |
| 删除包含今天 | 3 |

| 关闭采样默认 | 3 |

| 导入替换 | 4 |
| 删除全部官方导入 | 4 |

| 关闭实验性选项警告弹窗 | 5（固定 15 秒） |
