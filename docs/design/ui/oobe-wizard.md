# 首次启动向导（OOBE，想法记录）

> 状态：仅提问/记录，不加入当前修改。

## 可行性

可以做。插件前端已经在 Shadow DOM 里有完整 UI，可以用 localStorage 标记是否首次启动。

形式：

- 首次启动显示一个向导；
- 分步骤：欢迎 → 选择角色 → 大小/位置 → 点击/声音 → 数据与备份 → 完成；
- 可跳过；
- 以后可从设置重新打开；
- 升级后如需新功能说明，可用版本号只显示一次。

## 不建议放进向导的内容

- 不直接收集 API key；密钥应由 DSH 的凭据系统管理，前端不接触。
- 不强制用户完成所有设置。
- 不阻塞桌宠出现，向导可随时关闭。

## 入口选择

首次向导应先让用户选使用方式：

1. **作为新插件使用**：默认设置，从空白开始。
2. **从插件 JSON 导入**：无损恢复本地数据/设置，进入后按导入流程校验。
3. **从官方 ZIP 导入（仅用量）**：只导入官方用量/账单，不带设置和对话。

官方 ZIP 导入时要显示：

- 文件日期范围
- 时区（+08/UTC）
- 仅用量、不含设置/对话
- 冲突提示

## 参考流程

可参考：

- Windows OOBE：欢迎 → 区域/键盘 → 网络 → 账户 → 隐私 → 完成
- macOS Setup Assistant：语言 → 网络 → 账户 → 迁移数据 → 隐私
- 小米开机向导：
  - 欢迎页
  - 语言/地区
  - 连接 Wi-Fi
  - 登录/跳过
  - 隐私与条款
  - 完成

参考：[小米手机首次使用帮助](https://www.mi.com/service/redmi-phone/firstuse)

插件版建议流程：

1. 欢迎
2. 选择：新插件 / 插件 JSON / 官方 ZIP（仅用量）
3. 导入预览（如选导入）
4. 选择角色
5. 大小与位置
6. 点击、声音、动画
7. 数据与备份/账号状态
8. 完成
