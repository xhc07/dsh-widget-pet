# 确认弹窗设置（原高危倒数，设计）

> 状态：想法记录，未改插件代码。
> 加入 0–5 危险等级后，改名为「确认弹窗设置」，按等级配置。

## 0. 统一高危弹窗体系

所有高危弹窗共用一个服务/组件，例如：

```js
showHighRiskDialog({
  id,              // 'delete-data' | 'import-overwrite' | 'sampling-custom' ...
  title,
  body,
  confirmText,
  countdown,       // 由高危设置解析；0 = 不倒数
  onConfirm,
})
```

好处：

- 统一红色警告、倒数、确认按钮禁用；
- 以后新增高危功能直接接入；
- 统一处理“同时只能有一个高危弹窗”，避免叠层；
- 以后新增加高危相关设置也能复用。

### 自己的弹窗

「高危项目操作倒数提醒」把自己设为「关」时，使用**独立的固定弹窗**：

- 固定 15 秒；
- 不读取自身设置；
- 不复用可配置部分的倒数逻辑；
- 文案写死，避免被自身设置影响。

## 1. 设置位置

提醒设置里新增「确认弹窗设置」，按 0–5 级配置：

```text
0 提示   [倒数] [强制短语]
1 完成   [倒数] [强制短语]
2 注意   [倒数] [强制短语]
3 危险   [倒数] [强制短语] [默认 JSON 备份]
4 严重   [倒数] [强制短语] [默认 JSON 备份]
5 系统   固定 15 秒 + 固定短语“确认”
```

倒数选项：

| 选项 | 秒数 |
|---|---:|
| 关 | 0 |
| 短 | 3 |
| 中 | 5 |
| 默认 | 10 |
| 长 | 15 |

默认：

- 0–2：不倒数、不强制短语；
- 3：10 秒、短语关闭、备份默认勾选；
- 4：10 秒、短语开启、默认 `yes`、备份默认勾选；
- 5：固定 15 秒、固定 `yes`，不可改。

短语可选：

- `yes`
- `ok`
- `iknow`
- `确定`
- `我已阅读并已知风险`
- 自定义

总开关关闭时，自身关闭弹窗仍固定 15 秒。

## 2. 作用范围

管理**除自己以外**的所有高危操作/设置调整弹窗：

- 删除数据
- 清空全部用量
- 导入覆盖本地
- 关闭采样默认模式
- 其他不可逆/高危操作

设置为「关」时：

- 其他高危弹窗仍然提示后果；
- 但不再倒数，确认按钮可直接点；
- 自己设为「关」时例外，强制 15 秒。

普通确认弹窗不强制倒数。

## 3. 关闭自己

当用户把「高危项目操作倒数提醒」设为「关」时：

- 仍然弹高危提示；
- 写清关闭后的后果；
- 强制倒数 **15 秒**；
- 这 15 秒不受它自身设置控制；
- 只有“设为关”这一个动作强制 15 秒；从关改回其他值不需要。

设置回其他值时，不需要强制 15 秒。

## 4. 倒数 UI

- 显示操作名称和后果；
- 红色高危文案；
- 确认按钮在倒数结束前禁用；
- 显示剩余秒数；
- 取消按钮始终可用；
- 倒数结束才可确认。

## 5. 与清理的关系

清理确认：

- 显示清理范围、类别、时间跨度；
- 若勾选“包含今天”，增加红色提示“今日数据会被删除”；
- 确认按钮按上面的高危倒数规则禁用。
