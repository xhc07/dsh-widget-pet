# 角色大小滑块（想法记录）

> 状态：仅记录，未改插件代码。具体放在哪里、交互效果待定。

## 1. 当前实现

配置常量：

```js
SIZES = { small: 148, medium: 196, large: 258 } // 高度 px
```

宽度由高度计算：

```js
w = Math.round(h * 0.73)
```

因此当前三档约为：

| 档位 | 高度 | 宽度 |
|---|---:|---:|
| 小 | 148px | 108px |
| 中（默认） | 196px | 143px |
| 大 | 258px | 188px |

实现方式：

- `settings.size` 存 `small/medium/large`
- `applySize()` 写 CSS 变量 `--h`、`--spriteW`
- 气泡/待机/离开框/面板位置基于 `--h` 计算
- 右键菜单「大小」提供小/中/大三档
- 显示设置里的「显示与大小」按钮仍打开原来的右键菜单

## 3. 可选方案

### 方案 A：显示设置里加滑块

```text
角色大小   [滑块]  196px
           小   中   大
```

- 滑块连续调节；
- 小/中/大作为快捷吸附点；
- 右键菜单保留三档快捷切换。

### 方案 B：只保留菜单三档

- 不加滑块；
- 改动最小，但不满足“尽量自定义”。

### 方案 C：滑块 + 数字输入

- 滑块调大小；
- 右侧显示 px，可点击输入精确值；
- 与音量/采样交互一致。

## 4. 建议范围

当前素材是 400px 图，建议先限制：

- 高度：120–360px；
- 默认：196px；
- 步进：1 或 2px；
- 预设吸附：148 / 196 / 258；
- 超过 258 需要考虑气泡、徽章、面板是否被挤压。

不建议超过 360px，除非同时改容器宽度、面板锚点和屏幕边界限制。

## 5. 需要处理的问题

1. **容器宽度**：`.pet` 固定 276px，大尺寸可能超出。
2. **气泡位置**：基于 `--h`，变高后要保证不超出视口。
3. **面板位置**：面板固定 `right:320px`，角色变大可能重叠。
4. **拖拽边界**：`clampPos` 用实际 offsetWidth/Height，需要跟着更新。
5. **精灵清晰度**：素材最长 400px，超过 400px 会模糊。
6. **迁移**：旧 `size` 枚举映射到 px；新 `sizePx` 优先。
7. **菜单高亮**：当前尺寸正好等于预设时高亮对应档位。
8. **持久化**：滑块 `change` 时保存，拖动时实时应用。
